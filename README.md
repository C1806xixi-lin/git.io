# C1806xixi-lin | Portfolio

[Open the portfolio](https://c1806xixi-lin.github.io/git.io/). Three projects on GPU infrastructure for healthcare AI:

- [500 PFLOP/s healthcare AI compute center](https://github.com/C1806xixi-lin/C1806xixi-lin/blob/main/case-studies/healthcare-ai-compute-center.md): a reference design with sizing assumptions, trade-offs, and acceptance tests.
- [LLM inference GPU sizing skill](https://github.com/C1806xixi-lin/C1806xixi-lin/tree/main/skills/inference-gpu-sizing): an offline calculator and a 70B card-selection example.
- [LLM latency troubleshooting](https://github.com/C1806xixi-lin/llm-latency-troubleshooting): a reproducible lab using simulated traces.

For customer discovery, GPU selection, and acceptance tests, see the [technical presales toolkit](https://github.com/C1806xixi-lin/inspiration).

The original bilingual Rove Notes lives in [`rove-notes/`](./rove-notes/index.html).

## Preview locally
